# Scrapli Cfg

[scrapli_cfg](https://github.com/scrapli/scrapli_cfg) provides configuration-management
operations for scrapli v1 drivers. It has no v2 integration in this release.

nornir_scrapli removes the `scrapli_cfg` connection and six `cfg_*` tasks in the v2
line. Stay on `nornir-scrapli==2026.10.10` if you need them; see
[Migrating to v2](../user_guide/migrating_to_v2.md).
