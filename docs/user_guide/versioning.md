# Versioning

Please see the scrapli "core" [here](https://carlmontanari.github.io/scrapli/user_guide/versioning/) documentation for versioning information.

The v1-compatible nornir_scrapli line ends at `2026.10.10`. The next breaking release
requires scrapli v2; follow [Migrating to v2](migrating_to_v2.md) before upgrading.
